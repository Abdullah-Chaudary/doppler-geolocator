# Contributing

Thanks for your interest in Doppler Geolocator!

## Ground rules

- Small, focused PRs are easiest to review.
- For methodology changes, include a test or a reproducible example.
- Read the [Code of Conduct](CODE_OF_CONDUCT.md).
- Check [good first issues](https://github.com/Abdullah-Chaudary/doppler-geolocator/labels/good%20first%20issue) if you need a starting point.

## Development

```bash
git clone https://github.com/Abdullah-Chaudary/doppler-geolocator.git
cd doppler-geolocator

# open the app (no build step)
start web/index.html      # Windows
# or: open web/index.html  # macOS
# or: xdg-open web/index.html  # Linux
```

The web app is a single self-contained HTML file. Keep it that way unless a change genuinely requires a split.

## Reporting bugs

Open an issue with:

- What you did, what you expected, what happened
- Browser and OS
- A sample audio clip or ADSB snippet if relevant (redact anything sensitive)

## Security

Do not file security vulnerabilities as public issues — see [SECURITY.md](SECURITY.md).
